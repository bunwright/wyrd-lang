# Wyrd bōcland

Sēo gecȳþedlīce Wyrd handbōc, mid [Astro Starlight](https://starlight.astro.build/) getimbrod. Hire ēagwlit is handgeworht for Wyrd; hire stȳrend, sēċung, and bōcsceamu cumaþ of Starlight.

## Weorc

```sh
npm ci
npm run dev
npm run build
```

`npm run build` timbraþ þā fæstan bōc on `dist/`. `astro.config.mjs` hæfþ þone GitHub Pages grundweg `/wyrd-lang`.

## Bōcstōwas

- `src/content/docs/` — þā handbōc.
- `src/content/i18n/ang.json` — Ealdenglisc Starlight and Pagefind word.
- `src/components/` — Wyrd landingsīdan dǣlas.
- `src/styles/custom.css` — hīw, stafu, and andswaru.
- `public/` — fæste webbeġefta.

Nīwa `astro.config.mjs` þonne þū tramet tō þǣre sīdan setst.
